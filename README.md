# 🚀 NovaSpace - Flask Web Application

NovaSpace is a beginner-friendly full-stack web application
built using Python, Flask, HTML, CSS and JavaScript.

---

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- REST API
